# DouyinTV - 抖音电视版应用

这是一个专为 Android TV 设计的抖音客户端，通过 WebView 嵌入抖音网页，在智能电视上浏览和播放抖音短视频。

## ✨ 功能特性

- ✅ **完整嵌入抖音网页** - 嵌入抖音官方网页，功能完整
- ✅ **遥控器 / 空鼠操作** - 卡片焦点导航 + 空间光标兜底，菜单键失灵的遥控器也能用
- ✅ **自动播放下一个** - 视频播放完毕自动切换
- ✅ **Cookie 持久化** - 登录状态自动保存
- ✅ **横屏 / 竖屏 / 自动旋转** - 应用内设置切换，适配旋转支架
- ✅ **验证码遥控器拖动** - 出现滑块验证时按 ← / → 拖动、OK 确认，无需鼠标
- ✅ **兼容模式** - 旧系统 WebView 可切换手机版页面
- ✅ **崩溃自恢复** - WebView 渲染进程被系统回收后自动重建

## 🚀 快速开始

### 环境要求
- JDK 17+
- Android SDK
- Gradle 8.0+（已包含 Wrapper）

### 编译 APK

**Windows 用户** - 双击运行:
```
build.bat
```

**手动编译**:
```powershell
.\gradlew assembleRelease   # Release 版本(推荐)
.\gradlew assembleDebug     # Debug 版本
```

### APK 位置
```
app\build\outputs\apk\release\app-release.apk
```

## 📺 安装到电视

1. 将 APK 复制到 U 盘
2. U 盘插入电视
3. 使用文件管理器安装
4. 允许“安装未知来源应用”
5. 启动应用开始使用

> Fire TV / 老设备安装提示 “Failed to parse” 时：请确认下载完整（比对 Release 页的 SHA-256），并确认设备允许安装第三方应用。本项目 APK 为通用包（无原生 .so），不区分 32/64 位。

## 🎮 遥控器操作

| 按键 | 功能 |
|------|------|
| **上 / 下键** | 移动焦点 / 切换视频 |
| **左 / 右键** | 移动焦点；视频播放页快退/快进 10 秒 |
| **OK / 确认键** | 打开选中的视频卡片；播放页进入/退出全屏 |
| **长按 OK** | 打开设置菜单（没有菜单键的遥控器用这个） |
| **菜单键 / 设置键 / 红色功能键** | 打开设置菜单 |
| **返回键** | 退出全屏 → 页面后退 → 退出应用 |
| **播放 / 暂停键** | 播放 / 暂停 |

### 设置菜单

| 菜单项 | 说明 |
|--------|------|
| 扫码登录 | 点击页面登录入口，用手机抖音扫码 |
| 全屏播放 / 退出全屏 | 将当前视频铺满屏幕 |
| 画面方向 | 横屏 / 竖屏 / 自动旋转，立即生效并记忆 |
| 兼容模式 | 切换手机网页 UA，旧电视内核更流畅 |
| 刷新页面 | 重新加载抖音 |
| 清除缓存 / 退出登录 | 清理 Cookie 与缓存后重新加载 |
| 退出应用 | 关闭应用 |

### 验证码

出现滑块验证时，应用会提示：按 **← / →** 移动滑块，按 **OK** 释放。使用空鼠/鼠标时可直接拖动。

## 🧰 常见问题

| 现象 | 处理方式 |
|------|----------|
| 打开后蓝屏 / 一直转圈 | 确认安装的是最新版本（旧版布局缺陷会导致 WebView 高度为 0）。仍异常时按菜单键 → 清除缓存 |
| 遥控器按键没反应 | 长按 OK 打开设置；同一个遥控器在不同页面的左右键含义不同（播放页用于快进/快退） |
| 播放卡顿、滑动掉帧 | 设置菜单里查看底部显示的 WebView 版本。低于 Chrome/80 会在启动时提示更新“Android System WebView”；也可开启“兼容模式”使用手机版页面 |
| 登录弹窗反复出现 | 按菜单键 → 扫码登录；登录后 Cookie 会自动保存 |
| 验证码滑不动 | 用 ← / → 遥控器拖动，OK 释放；或使用空鼠直接拖动 |
| 视频播放中闪退 | 已加入渲染进程崩溃自恢复；仍然闪退请反馈设备型号 + WebView 版本（菜单底部可看到） |
| 安装解析失败 | 见上文 Fire TV 说明；Release 页提供 SHA-256 校验 |
